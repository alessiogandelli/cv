# Tutorial Images

This directory contains images for the n8n automation tutorial.

## Required Images

Add the following screenshots/diagrams to make the tutorial complete:

### 1. system-architecture.png
- Overview of the entire n8n workflow system
- Should show all three main components (indexing, sync, AI agent)

### 2. indexing-workflow.png
- Screenshot of the indexing workflow in n8n
- Shows nodes: HTTP Request → get file list → Filter .dart Files → Download Raw Content

### 3. sync-workflow.png
- Screenshot of the sync workflow in n8n
- Shows the GitHub Trigger and branching logic (delete/ingest)

### 4. telegram-example.png
- Screenshot of a conversation with the Telegram bot
- Example of creating an issue or asking questions about code

### 5. rag-diagram.png
- Diagram explaining the RAG process
- Shows: Query → Embedding → Similarity Search → Context Injection → Response Generation

## Image Guidelines

- Use PNG format for screenshots
- Keep file sizes reasonable (compress if needed)
- Make sure text in screenshots is readable
- Consider adding annotations or arrows to highlight important parts
